## 이미지 캡처 방법

1. 브라우저 개발자 도구 (F12)를 열고 디바이스 모드로 전환
2. 원하는 화면으로 이동
3. 스크린샷 도구를 사용하여 캡처
4. 이미지 파일을 이 폴더에 저장

## 이미지 최적화 팁

- 이미지 크기는 가능하면 1920px 이하로 제한
- JPG 형식 사용 권장 (용량 최적화)
- PNG 형식은 투명 배경이 필요한 경우에만 사용
- 이미지 압축 도구 사용 권장 (예: TinyPNG)
